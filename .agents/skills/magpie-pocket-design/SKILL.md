# Magpie Pocket 设计

把参考图中的轻透、克制与清晰层级实现成真实交互。用户最新明确要求优先于旧图中的交互；例如路由组现在自动跟随请求，旧图的下拉箭头不可照抄。

## 使用依据

- 首次实现或大幅调整页面，阅读 [设计规范](references/design-spec.md)。
- 需要精确数值时读取 [tokens.json](references/tokens.json)；项目已有 `Tokens.kt`、`Theme.kt` 和设计组件时复用它们，发现差异先核对当前需求，不再造第二套颜色常量。
- 对齐整体气质和空间关系时查看 [用户确认的参考图](assets/routing-reference.png)。它是视觉基线，不是 Android 像素尺寸表，也不替代最新交互要求。

## 视觉决定

- 冷白底、右上淡紫与左侧浅蓝环境色；深色使用深灰蓝，不反转成纯黑荧光界面。
- 玻璃放在悬浮导航、控制区、浮层；数据面板实色、文字锐利。通过透明色、高光和轻阴影表达材质，不模糊前景，也不把普通透明卡片宣传成真实光学折射或官方 Apple 材质。
- 浅色鸟标为深灰圆角底与浅色鸟；深色沿用项目的反色标识。Magpie 项目复用现有品牌路径和许可。仅借用风格的其他产品保留其自己的品牌。
- 统一 20dp 页边距、24dp 数据卡圆角、32dp 底栏圆角、48dp 最小触控区域。窄屏必要时可用 16dp 边距，不整体缩小字体。
- 信息顺序是标题与状态、时间口径、关键指标、核心内容、解释或明细。只给真正重要的数值较大字号，避免每一行都装进卡片。

## 交互决定

- 四标签悬浮底栏保留文字；原生状态栏和导航栏安全区参与布局，最后一条内容必须能完整滚到可见位置。顶部品牌栏以 64dp 为最小高度，随大字内容增高，正文顶部占位跟随实测高度。
- 路由由真实请求自动决定组、供应商、账号和路径，不能默认选第一个组伪造状态；历史请求固定，返回实时后恢复自动跟随。未提出新的暂停需求时，不另造“自动跟随”开关。
- 动画只能表达真实处理中状态；完成后停止持续流动。系统减少动态效果、应用减少动态效果、后台和离线必须让视觉动画停止，不能通过清空数据实现。
- 每个开关显式指定选中与未选中的圆点、轨道和边框。选中轨道用 accent，浅色圆点用白色，深色圆点用深色背景；圆点与轨道对比至少 3:1，不能只设置 checkedThumbColor。
- 开关旁有可理解的文字和可访问状态，整行至少 48dp；状态不能仅靠同色变化表达。浅色、深色和再次点击关闭都要检查。
- 错误、离线、重新连接与成功状态明确区分；演示数据标明“演示”。缺失数据保留未知，不补造请求、余额或状态。

## 交付检查

检查实际页面而不只看代码：320dp 与常规手机宽度、浅/深色、开关开/关、字体放大、底部遮挡、空态/错误/处理中/历史固定。涉及动效时比对两帧；涉及自动路由时至少让两个组依次产生请求，确认图确实切换。

在本项目中保留认证隔离、加密存储、只读查看与设备本地时间语义。不要把真实服务地址、账号、凭据、私钥或本机路径放入示例、截图或交付包。未要求后台连接只表示不添加后台保活，不得把原有前台联网或真实数据擅自改成离线演示。本 skill 不授予发布、发送消息或访问生产系统的权限。
